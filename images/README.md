# Afbeeldingen

Zet hier je eigen foto's, bij voorkeur in WebP of JPG en niet groter dan ongeveer 300 KB per stuk, zodat de site snel laadt.

Gebruik alleen foto's waarvan je de rechten hebt, bijvoorbeeld eigen foto's of beelden met een duidelijke gebruiksvrije licentie. Overname van foto's van andere websites is niet toegestaan.

Voorbeeld van gebruik in een HTML-pagina:

```html
<img src="images/hero-kamperen.webp" alt="Tent op een kampeerplek bij zonsopgang">
```
